### Step 3: Ensure Absolute Pathing in `app.py`
To prevent `FileNotFoundError` when deployed on a cloud server, your `app.py` must use dynamic path resolution to locate the `models/` folder. Here is how your model loading block should look inside `app.py`:

**`app.py` (Model Loading Section)**
```python
import os
import streamlit as st
import torch
from networks import ConditionalGenerator, ConvAutoencoder, VAE

# App Config
st.set_page_config(
    page_title="Generative Fashion Design Studio", layout="wide"
)

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# Robust path resolution for cloud deployment
current_dir = os.path.dirname(os.path.abspath(__file__))
models_dir = os.path.join(current_dir, "models")


@st.cache_resource
def load_models():
  # Load cGAN Generator
  cgan = ConditionalGenerator(100, 10).to(device)
  cgan.load_state_dict(
      torch.load(
          os.path.join(models_dir, "cgan_generator.pt"),
          map_location=device,
          weights_only=True,
      )
  )
  cgan.eval()

  # Load VAE Model
  vae = VAE(latent_dim=20).to(device)
  vae.load_state_dict(
      torch.load(
          os.path.join(models_dir, "vae.pt"),
          map_location=device,
          weights_only=True,
      )
  )
  vae.eval()

  # Load Denoising Autoencoder & Threshold
  denoise_ckpt = torch.load(
      os.path.join(models_dir, "denoising_autoencoder.pt"),
      map_location=device,
      weights_only=False,
  )
  denoiser = ConvAutoencoder().to(device)
  denoiser.load_state_dict(denoise_ckpt["state_dict"])
  denoiser.eval()
  threshold = denoise_ckpt["threshold"]

  return cgan, vae, denoiser, threshold


cgan_gen, vae_model, denoise_model, anomaly_threshold = load_models()
```[cite: 2]
